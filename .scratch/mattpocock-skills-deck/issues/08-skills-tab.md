# 08: Skills tab

**What to build:** A Skills tab lists every Matt skill from a fixed catalogue of 38 names, grouped as engineering, productivity, misc and in-progress, each with a one-line purpose. Installed skills offer Load (fills `/<skill>`) and Details (shows the skill's SKILL.md in the Pane). Uninstalled ones show greyed out as "not installed". Skills that are not Matt skills never appear.
